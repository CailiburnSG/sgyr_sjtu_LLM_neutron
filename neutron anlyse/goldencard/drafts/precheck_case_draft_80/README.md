# 80 个预检案例草稿（探索稿，已被 event_groups 平衡稿替代）

> 当前训练/验证金标准使用 `../precheck_case_balanced_80_eventgroups/`：它仅从 `event_groups/` 的
> 80 个事件原子构造，并严格保证 A1–A4 各 20 例。本目录保留为原始时间簇切分方案的历史探索稿，
> 不应作为当前实验集。

本目录将 30 个聚合事件组合与 50 个真实单通道事件组合汇总为 80 个待复核案例。它不是合成数据：
所有事件均可回溯到 `eventcard/output/` 的真实卡片。

## 家族隔离

新增单通道组合与前 30 个聚合组合可能来自同一原始时间簇。因此每条案例都有 `case_family_id`：

- 同一 `case_family_id` 的案例不得被拆分到训练集和测试集两侧；
- 不同来源事件卡文件内，案例不复用同一事件卡 ID；
- 这一设计增加了事件组合粒度，但不把同一原始异常误报为独立样本。
