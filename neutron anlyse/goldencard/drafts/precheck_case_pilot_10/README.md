# 首批 10 个预检案例草稿

本目录是新的、独立的**预检案例**试标集。每一条记录的任务单位是一个真实事件组合 `X`，而不是
旧的单事件模板或旧候选包。

## 边界

- 仅使用 `eventcard/output/` 中已有的真实事件卡生成 `X`；
- 不读取、不复制、不默认认可任何旧 `goldencard/cards/`、`goldencard/event_groups/` 或既有
  `goldencard/drafts/` 中的证据—行动关联；
- `pilot_10_cases.jsonl` 含事件组合摘要、可审计的来源事件 ID，以及本轮**重新判断**的
  证据—行动草案；所有记录均为待人工复核状态，不是正式答案；
- 四项固定建议的定义仍以 `../../固定检查行为.md` 为准；第一版每个案例至多标注一项，且没有直接证据就不标注建议。

## 为什么先做 10 个

这是试标，不是正式训练/测试划分。它用于确认：

1. 事件组合窗口是否表达了预检输入；
2. 单一优先建议及其证据是否足够；
3. 四项固定检查建议能否被证据直接支撑；
4. 标注者对 `X × Y × Z` 的 0/1/2 支撑评分是否能稳定一致。

通过试标并冻结规则前，这 10 个案例都不得被报告为正式金标准或用于最终结果。

## 文件

- `build_pilot_cases.py`：从原始事件卡可重复生成候选 `X`；
- `pilot_10_cases.jsonl`：10 个待标注案例；
- `pilot_case_selection.md`：每个案例的窗口和覆盖理由。
- `一页总览表.md`：供人工快速审阅的“事件组合—证据—建议”表格。
