# 八个金标准事件组

本目录将当前金标准事件空间固定为八个组：四种可观测事件状态乘以单通道/多通道时间簇范围。
每个 JSON 文件恰含 10 张事件卡，共 80 张。

```text
short_zero      × single_channel / multi_channel_temporal_cluster
sustained_zero  × single_channel / multi_channel_temporal_cluster
positive_spike  × single_channel / multi_channel_temporal_cluster
negative_drop   × single_channel / multi_channel_temporal_cluster
```

这 80 张卡统一作为金标准事件模板，用于后续的事件—证据—检查行为标注与量化评测。
