# Qwen3.8-Flash：Top-10 固定训练示例上下文

## 设置

- 验证：冻结的 20 例，四项行动各 5 例。
- 检索：沿用 B0 的同一 BM25 Top-10 候选证据包；B0、零样本 B1 与本变体的候选包完全一致。
- 上下文示例：从 60 个训练例中固定 8 例，A1--A4 各 2 例；选择规则、ID 与训练来源仅保存在本变体的 manifest 中。
- 去标识化：`goldcard_id` 不送入模型。其数字区间与本构造数据集的行动类别相关，故仅用于模型外的结果对齐和评分。
- 这不是参数微调：Qwen 权重未更新；8 个训练例仅作为每次 API 调用的固定上下文。

## 同候选包对照

| 方法 | Action Accuracy | Action Macro-F1 | 语义—行动对 F1@10 |
| --- | ---: | ---: | ---: |
| B0：BM25 + 机械标签投票 | 0.250 | 0.192 | 0.152 |
| B1：零样本 LLM 直接判断 | 0.500 | 0.375 | 0.307 |
| B1：8 个固定训练示例 + LLM | 0.850 | 0.854 | 0.445 |

固定示例使模型不再把 A3/A4 系统性吸收到 A2：A3 的 F1 为 0.889（4/5 例正确），A4 的 F1 为 1.000（5/5 例正确）。三项错误为：1 个 A1→A2、1 个 A2→A1、1 个 A3→A2。

## 成本与解释边界

- JSON 合法率与输出合同合规率均为 1.000。
- 固定示例：total token = 589,769，单例平均延迟 = 3.768 s。
- 去标识化零样本：total token = 84,563，单例平均延迟 = 3.400 s。

因此，固定示例带来显著行动识别增益，但 prompt token 约为零样本的 7.0 倍。这是首个、按“每类两例且含直接支持卡”规则冻结的示例池结果；后续正式结论还应使用其他预先冻结的示例池或模型复核，避免把单一示例池的效果泛化为稳定上限。
