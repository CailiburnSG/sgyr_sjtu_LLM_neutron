# 预检实验

本目录保存对正式金标准的可重复实验脚本及其输出。实验输入在
[`../gold_standard_80_eventgroups/`](../gold_standard_80_eventgroups/)；不得在运行时改写该目录中的案例或标签。

- [`B0/`](B0/)：BM25 从 300 张卡中检索 top-K，并按检索卡的既有标签投票行动；不使用 LLM。该目录包含代码、原始输出、指标与分析；
- [`B1/`](B1/)：与 B0 共用 K 网格的 BM25 候选检索，再由多个 LLM 联合选择证据与行动；当前已冻结设计与配置模板。

整体设计与 B0--B3 对照见 [`../实验执行指南.md`](../实验执行指南.md)。B1--B3 的代码和结果将以同样方式建立独立子目录。
