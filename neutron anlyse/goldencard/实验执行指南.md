# 金标准集 v1 实验执行指南

## 目标与边界

本实验评价的是**证据约束的预检行动选择**：由事件组合选择可引用证据，并给出一项固定检查建议。
它不评价、也不宣称具体故障原因诊断准确率。

当前正式数据集为 [`gold_standard_80_eventgroups/`](gold_standard_80_eventgroups/)，含 80 个案例：

- A1--A4 各 20 例；
- 每例 1--4 个事件原子；
- 每例 3 张同一检查意图的并列证据卡；
- 每例 1 项固定检查建议。

本阶段接受两项数据集设计前提：事件形态与检查建议之间的对应关系本身就是模型应学习的预检规律；
事件已按当前方案匿名化处理，因此不将同记录或模板来源视为本阶段的泄漏限制。

## 系统对照

| 系统 | 流程 | 目的 |
| --- | --- | --- |
| R（诊断） | 事件组合 → BM25 top-K | 只测候选包是否覆盖正确资料，不输出建议。 |
| B0 | 事件组合 → BM25 top-K → 机械标签投票 | 不用 LLM 的传统检索—投票基线。 |
| B1 | 事件组合 → BM25 top-K → LLM 选证据与建议 | 检验 LLM 能否理解传统检索得到的候选。 |
| B2（主方法） | 事件组合 + 全部 300 卡 → LLM 选证据与建议 | 让 LLM 直接在全库中完成证据选择与行动选择，无 BM25 漏检。 |
| B3（消融） | 事件组合 + 金标准三证据 → LLM 选建议 | 给定正确证据，检验 LLM 的证据使用与行动选择上限。 |

R 是模块诊断，不属于主系统对照。B0 输出 BM25 top-K 证据和标签投票建议，但不能理解多事件组合、
证据正文或证据—行动的联合关系；它是传统检索基线，不应作为可部署的证据辅助报告系统。B1--B3
使用相同的一组 LLM、相同温度和相同输出合同，才构成 LLM 参与的端到端对照。

## B0 规则

1. 将事件类型、通道范围和作用范围直接串成查询，不写入“事件类型 → 建议”的规则；
2. 用 BM25 在 300 张卡中取 top-K；
3. 仅根据 top-K 卡已有的 `applicability` 标签向四项行动投票，并按各行动标签集合大小归一化；
4. 最高分行动即为输出；同分时按冻结的行动 ID 顺序处理。

行动标签与 `applicability` 的对应来自四项行动的公开定义，例如 `channel_comparison` 支持 A2、
`signal_path_context` 支持 A4。B0 在预测时不读取任何案例的金标准行动或三证据组合。

## 评价

### B0

- 行动 Accuracy；
- 四项行动的 Precision、Recall、F1 与 Macro-F1；
- 混淆矩阵。
- 严格金标准的 Evidence Precision@K、Recall@K、F1@K。
- 金标准行动证据覆盖@K：top-K 中至少一张属于该案例正确建议类别的直接支持卡；这是候选包是否提供正确资料的事后指标，不是行动结论正确率；
- 金标准行动候选 Precision@K：top-K 中属于该正确建议类别直接支持卡的比例。

### B1--B3

在 B0 行动指标之外，增加：

- Evidence Precision@K、Recall@K、F1@K；
- 金标准行动证据覆盖@K / 候选 Precision@K：候选包中属于该正确建议类别的已确认直接支持卡的命中与比例；
- `(evidence_id, action_id)` 对的 Precision、Recall、F1；
- JSON 合法率、未知证据 ID 率、无依据行动率；
- 人工盲审的引用支撑率和过度诊断率。

## 执行顺序

1. 固定 `gold_standard_80_eventgroups`、300 张证据卡、行动定义和模型版本；
2. 运行 B0，保存原始逐例预测和指标；
3. 对 R/B0 固定并保存每个 K 的 BM25 候选包；
4. 以同一 JSON 合同实现 B1、B2、B3，固定提示词、温度、输出上限与模型集合；
5. 汇总行动、证据、联合和安全指标；
6. 对 B1--B3 的报告进行盲审，论文中明确表述为预检行动选择，不外推为故障诊断。

## 当前可运行命令

在仓库根目录执行：

```bash
python3 'neutron anlyse/goldencard/experiments/B0/run_k_sweep.py'
```

结果写入 `goldencard/experiments/B0/results/`，不会改写金标准 JSONL。B0 的完整方法与结果分析见
[`experiments/B0/README.md`](experiments/B0/README.md)。
