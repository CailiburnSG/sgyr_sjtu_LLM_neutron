# 极简事件卡与受控检索原则

## 1. 事件卡的边界

事件卡只记录容易、确定、可计算的观测现象：

- 零值与连续零值；
- 尖峰与突降；
- 单通道事件；
- 多通道近同步事件；
- 部分通道与广泛通道事件。

第一版不试图自动识别物理机理、设备故障或因果关系。

## 2. 极简事件卡

```json
{
  "event_id": "A1_1-E017",
  "record_id": "A1_1",
  "event_type": "short_zero | sustained_zero | positive_spike | negative_drop",
  "time_start": "...",
  "time_end": "...",
  "channels": ["RIC1011", "RIC1012"],
  "scope": "single_channel | multi_channel_temporal_cluster",
  "evidence": {
    "duration_s": 2,
    "detector": "zero_run"
  },
  "context_status": {
    "before": "clean | contaminated | unavailable",
    "after": "clean | contaminated | unavailable"
  },
  "source": "原始 CSV / 工具版本"
}
```

底层数值工具可保存更多细节；给检索和 LLM 的卡片只保留以上关键字段。

## 3. 上下文：由前后事件卡组成

不另建复杂的上下文模型。每张卡只需检查：

```text
前一张事件卡是什么？
后一张事件卡是什么？
相隔多久？
```

若前后窗口包含其他事件，则该侧上下文记为 `contaminated`，不能称为稳定基线或已恢复；若记录边界不足，则记为 `unavailable`。

## 4. 检索原则

> 以已观测事实为锚，以预检目的为限制；不将未经证实的物理解释写入查询。

检索查询由四部分组成：

\[
q(e)=\text{测量对象}+\text{观测现象}+\text{通道范围}+\text{预检目的}
\]

| 部分 | 来源 | 例子 |
|---|---|---|
| 测量对象 | 固定领域词 | neutron current / nuclear instrumentation |
| 观测现象 | 事件卡类型 | zero output / transient spike / abrupt drop |
| 通道范围 | 卡片范围 | single channel / multiple synchronous channels |
| 预检目的 | 固定任务词 | online monitoring / data quality / verification |

例如，单通道短零值可构造为：

```text
nuclear instrumentation single channel transient zero output
online monitoring data quality verification
```

多通道近同步尖峰可构造为：

```text
neutron instrumentation multi-channel synchronous transient spike
online monitoring signal noise data acquisition verification
```

其中 `noise`、`data acquisition` 只表示需要查找的资料方向，不是已经确认的原因。

## 5. 固定映射表

第一版不让 LLM 自由改写检索查询，而使用受控术语映射：

| 事件卡类型 | 检索核心词 |
|---|---|
| 短零值 / 连续零值 | zero output, signal dropout, missing signal |
| 尖峰 | transient spike, signal spike, noise transient |
| 突降 | abrupt drop, signal loss, transient deviation |
| 单通道 | single channel, channel comparison |
| 多通道同步 | multi-channel synchronous, common-mode, data acquisition |
| 部分通道 / 广泛通道 | partial-channel / multi-channel pattern |

精确时间戳、内部通道编号、原始峰值数值和未经证实的故障/因果结论不进入语义检索查询；它们仅用于事件卡、报告事实核验和回查。
