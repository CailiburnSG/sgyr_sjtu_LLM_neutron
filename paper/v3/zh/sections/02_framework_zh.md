# 2. 场景、数据边界与证据约束接口

## 2.1 研究对象与披露边界

本研究的测量资源来自同一核电厂采集周期内的中子电流历史档案。研究对象是核电厂中子仪表的多通道时间序列及其可审查的信号现象；本文不尝试仅依据这些记录识别反应堆类型，也不将其用于直接重建反应堆物理状态。

为保护现场信息，本文暂不公开反应堆型号、厂站身份、具体仪表系统名称或其他可识别信息。这一限制应被视为披露边界，而不是对研究问题的替代描述：后文只陈述足以理解数据组织、方法适用范围与实验结论的事实。若获得进一步许可，应在本节据实补充反应堆/探测器类别及其与监测任务的关系；在此之前，不对具体堆型作推断。

## 2.2 测量档案及其角色

档案包含 42 条多通道 CSV 记录，来自四套传感器。每条记录包含一列时间信息和 7 个中子电流通道；典型记录具有约 $6\times10^{5}$ 个样本、约 1 s 的采样间隔，并覆盖多日窗口。组内通道具有相对布置关系，故通道顺序并非任意的特征列，而是与仪表位置有关的测量组织方式。

原始导出文件可能存在局部时间戳紊乱或非单调片段，因此时间顺序校正是任何观测前的必要步骤。更重要的是，测量档案只提供可观察的信号现象，而不提供可直接用于监督学习的故障标签。突刺、零值段、滞后、共变变化和极值等结果在本研究中被定义为**描述性观测**；它们不是附着于原始 CSV 的故障注释，也不直接构成物理机理或根因结论。

## 2.3 技术证据资源及其角色

与测量档案互补的是带有来源 metadata 的核仪表与控制技术资料库。该资源提供可检索、可定位的文献证据，而不是故障标签数据库。资料库同时包含预设的权威核心资料与同领域补充资料：前者服务于部署中的来源策略，后者扩大可检索的技术覆盖范围。两类资料都可能相关，但“相关”不自动等同于“应优先作为工程依据”。

测量资源与文献资源只通过受控的语义接口连接。首先，由确定性 probes 将测量记录转换为 observation packet；随后，结构化告警摘要将已观察到的现象表达为检索意图；最后，检索到的可定位段落才可支持候选解释。由此，未经处理的波形不会被直接提升为诊断结论，文献段落也不会被误写为对原始波形的直接解释。

## 2.4 证据约束接口与责任边界

本文的接口连接测量侧与证据侧。测量侧包含时间顺序校正、确定性 probes、可回溯的 observation packet 和 structured alert summary；它们共同构成对原始记录的可审计观察。证据侧以该摘要作为受控检索描述，完成 authority-aware technical retrieval，并组织 citation-bearing candidate interpretation。
