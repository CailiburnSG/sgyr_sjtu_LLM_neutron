# 4. 分层评价设计：检验接口与来源治理

本章评价 measurement-to-evidence interface 的可追溯性及其证据侧检索行为，不报告自动故障诊断、根因识别或生成文本的工程正确性。评价对象分为两个层次：测量侧检查一份 observation packet 能否回溯到确定的输入、参数和派生产物；证据侧检查在同领域资料逐步加入时，仅依赖语义相似度的检索是否仍能满足预先指定的核心来源可见性要求。候选解释的工程适用性需要运行/维护上下文和领域专家复核，不作为本章的自动化评价对象。

## 4.1 观测层的可追溯核查

观测层不以故障标签或分类准确率评价，而核查 observation packet 的可回溯性。其目的还在于约束测量侧 agent 的报告生成：condition report 只能组织记事板中已保存的观察，不要求 agent 自行从原始波形推断新的测量事实，从而降低报告质量对 agent 能力的依赖。核查 active record、时间排序结果、分析参数、工具输出和记事板字段是否相互对应；对代表性 trace，还核对完整报告中的关键描述和 compact alert summary 中的字段能否回指至相应脚本输出及时间—通道位置。第五章据此展示一条完整链条。

## 4.2 证据资料库、来源要求与检索协议

证据侧使用第 3 章定义的 64 份技术资料：13 份 IAEA 资料构成预先指定的核心来源集合 $\mathcal{D}_{\mathrm{core}}$，51 份核仪表与控制同领域资料构成补充集合 $\mathcal{D}_{\mathrm{sup}}$。补充资料并非无关噪声，也不预设为低质量；它们反映了实际资料库中同领域技术证据随资料范围扩展而不断加入的情形。将 IAEA 资料预先指定为核心，并不排除补充资料的技术价值，而是施加一项来源要求：当检索范围扩展时，核心权威来源集合仍应在结果中保持足够可见。

当前评价首先测量无显式来源重排的语义检索与这一目标之间的偏离，而不预设某种过滤或重排策略已经改善了结果。若后续实现来源过滤、来源优先或软重排，则应在相同 query 和资料库上另设对照，评价其对段落相关性与核心来源可见性的共同影响。

令 $\mathcal{D}_{\mathrm{sup}}^{(m,t)}$ 表示第 $t$ 次试验中抽取的 $m$ 份补充资料，活跃资料池定义为

$$
\mathcal{D}_{m,t}=\mathcal{D}_{\mathrm{core}}\cup\mathcal{D}_{\mathrm{sup}}^{(m,t)},
\qquad m\in\{0,5,10,\ldots,51\}.
$$

当 $m=0$ 时，仅检索核心资料；当 $m>0$ 时，对同一规模的补充资料进行固定随机种子下的重复抽样。每次检索返回前 10 个段落。该设计不把“资料扩展”简单等同于添加噪声，而是观察相关补充资料加入后，排名与来源可见性如何共同变化。

查询集由人工固定和复核，不由语言模型生成。`nomic-embed-text` 字符分块扩库协议使用中英文的简短核心术语与测量短语；MiniLM encoder 对照协议另加入由 observation packet 保留的线索形成的技术细节表述，例如重复短时偏离、同步零值段和高通道共变而无明显滞后。后者用于检验结构化观察的表述方式是否改变证据可见性，而不构成对设备机理的自动命名。

`nomic-embed-text` 字符分块扩库协议覆盖 17 个已保存的分块长度—重叠率配置，分块长度取 800、1000、1200 和 1500 字符，重叠率取 50、80、100、120 和 150 字符，并保留有效组合；每个非零扩库规模下均进行 100 次补充资料抽样。该协议考察资料范围、语言和分块边界，并同时提供 self-retrieval 所需的已保存索引。

MiniLM encoder 对照协议在相同资料库、top-10 规则和来源指标下，使用多语种的 `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` 与通用的 `sentence-transformers/all-MiniLM-L6-v2` 表示文本。字符分块设置为 800/80、1200/120 和 1500/150，并比较简短 query 与技术细节 query；独立的固定词数设置为 240 词、24 词重叠。各 MiniLM 非零扩库条件进行 10 次补充资料抽样。不同 encoder 或不同分块单位的余弦分数不直接横向比较；对照关注资料扩展后的来源可见性是否跨 encoder 出现，以及 query 表述的影响是否随表示模型和语言而改变。

## 4.3 指标及其解释范围

本研究以归一化向量的余弦相似度作为无显式来源约束的透明 dense-retrieval baseline。其最高分仅反映语义近邻检索行为，不被解释为工程正确性，也不自动满足核心权威来源的优先要求。对于检索列表 $R_k(q)=\{d_1,\ldots,d_k\}$，核心来源可见性定义为

$$
\operatorname{CorePriority@}k(q)=
\frac{1}{k}\sum_{i=1}^{k}
\mathbb{I}\!\left(\operatorname{doc}(d_i)\in\mathcal{D}_{\mathrm{core}}\right).
$$

同时记录第一条核心来源段落的排名。`CorePriority@k` 衡量的是检索结果对预设来源要求的符合程度，不衡量人工判断的段落相关性，也不表示核心资料是唯一可接受的技术资料。

为核查资料分块本身是否仍能找回已知来源，进行 IAEA core 的 self-retrieval：从核心资料中抽取段落，以首句、标题、随机窗口或领域术语构造 query，分别报告 exact-chunk 与 same-document 的 Recall@10，以及 MRR。前者检验是否找回同一段落，后者允许因重叠分块而返回同一文档中的相邻段落。该核查解释检索单元与分块边界的影响，与上述来源可见性评价回答不同问题。

## 4.4 结果的解释范围

本章在固定资料库和 query 协议下控制资料范围、查询表述、语言、encoder 和分块方式，检索过程不包含语言模型即时改写 query。结果用于刻画这些条件如何改变核心来源的可见性，以及这一变化是否与最高余弦相似度背离；不同语言、encoder 或分块方式不据此作普适排名。第五章直接围绕观测可追溯链和来源可见性结果展开。
