# V3 中文源稿

这里是 V3 的中文论文源稿，也是当前唯一允许新增论证内容的正文位置。先将一个小节的事实、主张、证据边界和图表任务写清楚，再翻译到 `../en/` 的同编号文件。

## 工作规则

1. 中文小节完成论证核对后，才创建或更新相应英文小节。
2. 英文稿是忠实、可发表的表达，不得增加中文稿没有的实验结论、事实或因果解释。
3. 事实不确定、披露权限不明或缺少专家复核时，在中文稿明确标为待确认；不得以英文修辞掩盖该边界。
4. 图表先在中文小节说明“它回答什么问题、证据来自哪里、结论不包括什么”，再制作中英文图注或图中文字。

## 文件布局

- `main_zh.md`：中文论文总入口、标题、摘要状态和章节链接。
- `sections/`：按论文阅读顺序撰写的中文正文。
