# V3：证据约束诊断辅助论文重构稿

V3 是基于导师意见重新构建论证的新稿。当前阶段先以中文确定问题、场景、唯一 idea、验证边界和章节逻辑；在论证稳定前不复制 V2 的 LaTeX 正文。

文件说明：

- `00_argument_zh.md`：中文论证稿，定义场景、问题、idea、方法因果链与边界。
- `01_outline_zh.md`：中文章节提纲与每节承担的论证任务。
- `terminology_zh_en.md`：V3 固定中英术语表。
- `zh/`：中文源稿。所有论证、事实、图表任务和结果解释首先在此完成。
- `en/`：英文镜像稿。仅在对应中文内容确认后翻译与润色，不作为独立扩写来源。

V2 仅作为可回溯的素材库；从 V2 迁入任何文字、图或表前，必须确认其服务于 V3 的中心论点。

中文与英文稿的同步规则见 `zh/README.md` 与 `en/README.md`。两套稿件保持相同的章节编号，但不共享正文文件，以避免翻译过程覆盖中文论证。
