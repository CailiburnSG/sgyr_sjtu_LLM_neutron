\subsection{Constrained tool use and runtime reliability}
\label{sec:agent-design}

The workflow treats runtime reliability as a methodological requirement rather than an implementation afterthought. In a multi-step tool-using workflow, mutable paths, malformed action payloads, unregistered actions, and unconstrained narrative transfer can otherwise break the chain between a measurement record and its evidence-linked output. The final protocol converts these workflow risks into explicit constraints and auditable artifacts, summarized in \cref{tab:agent-design}.

\subsubsection{State ownership and constrained actions}
The local LLM planner selects the next analysis action, but it does not own the authoritative state. The Python router executes registered analyzers and updates the workspace blackboard. Once initialization has completed, probes cannot silently switch to another raw or sorted file because the active record is resolved from that state. Missing initialization causes the workflow to fail closed. This moves data-path ownership from mutable model strings to a runtime contract.

At the action interface, the router tolerates common presentation noise while retaining a narrow execution boundary. ReAct~\citep{yao2023react}, Gorilla~\citep{patil2024gorilla}, and Toolformer~\citep{schick2023toolformer} motivate tool-using language-model workflows, but the present protocol narrows their execution boundary: it extracts the first brace-balanced JSON object or array even when the model adds Markdown fences or short commentary, then validates that the \texttt{action} field names a registered probe. The protocol does not claim perfect structured generation; instead, it makes malformed or invented actions visible and non-executable.

\subsubsection{Evidence-constrained output boundary}
The runtime constraints continue beyond tool execution. A multi-page condition narrative is useful for audit but unsuitable as the sole retrieval query, because it mixes many observations with incidental detail. The system therefore exposes a compact alert summary to the retrieval layer and requires memo claims to remain linked to retrieved passages. Hallucination surveys~\citep{ji2023hallucination} motivate this guardrail against fluent but unsupported interpretation. The automated chain produces observations and evidence-linked candidate interpretations; an engineer remains responsible for judging context, support adequacy, and any physical conclusion before use.
